# Práctica 1: Control de Versiones

Alumnos: Santiago Sánchez Rodríguez y Casasola Avalos Diana Valeria
Carrera: Ingeniería en Sistemas Computacionales (ESCOM - IPN)

## Índice
1. Introducción:
En este repositorio se documenta la práctica 1, enfocada en el dominio de Git y GitHub para la gestión de versione y el trabajo colaborativo basado en ramas.
2. Desarrollo de la práctica:
-Se creó y configuró un repositorio remoto en GitHub.
-Se implementó el control de versiones local clonando el repositorio.
-Se redactó la documentación inicial README.md y las reglas de exclusión .gitignore.
-Se realizaron múltiples confirmaciones con mensajes descriptivos sobre los avances.
-Se practicó el flujo de trabajo basado en ramas creando una rama secundaria, abriendo un Pull Request en GitHub y ejecutando su fusión.
3. Conclusiones:
El uso de sistemas de control de versiones como Git es muy útil, ya que evita la pérdida de información, permite rastrear errores con precisión y facilita la colaboración segura sin interferir en el código fuente principal.
